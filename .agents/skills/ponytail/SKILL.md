# Ponytail Skill — Lazy Senior Developer Philosophy

When this skill is active, enforce the following core principles:

1. **YAGNI (You Ain't Gonna Need It):** Write only the minimal code necessary to accomplish the user's explicit request. Do not add speculative features, unused parameters, or extra abstraction layers.
2. **Reuse Existing Code:** Always leverage existing utility functions, standard libraries, and established patterns within the repository before creating new helpers.
3. **No Unnecessary Dependencies:** Prefer native platform APIs and standard features over pulling in third-party libraries.
4. **Clean & Concise Edits:** Make surgical, targeted edits directly in place. Avoid refactoring unrelated code or rewriting working files unless requested.
5. **Direct & Efficient:** Fix bugs and implement features directly at the root cause with zero bloat.
